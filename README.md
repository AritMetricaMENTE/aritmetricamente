# aritmetricamente
AritMetrícaMENTE es un emprendimiento que busca ofrecer servicios en tres (3) lineas de acción diferentes: 1. Atención psicológica para niños, adolescentes y adultos; 2. Desarollo de instrumentos de medición psicólogica; 3. Asesoría en investigación en variables del comportamiento humano.
